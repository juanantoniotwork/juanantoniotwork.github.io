03 Proyectos

Proyecto insignia

reparaelec

Asistente de IA con RAG para que técnicos de reparación consulten manuales de electrodomésticos en lenguaje natural, en vez de bucear en PDFs de cientos de páginas. Los manuales se indexan como embeddings en pgvector y las respuestas se generan vía la API de Claude. Incluye versión web y app móvil.

  • Laravel 11
  • Next.js
  • PostgreSQL
  • pgvector
  • Ollama
  • API de Claude
